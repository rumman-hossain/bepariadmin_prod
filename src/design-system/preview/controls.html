Controls

Nine of these are new. Several exist because their predecessor was unusable rather than merely ugly.

Buttons

Three sizes — 30 / 36 / 42px — against the previous kit's 32 / 40 / 48, which no other control matched. Jute is the attention fill and never carries button text at small sizes; where a warning needs text, it uses warn.

Fields

As registered on the trade licence.
Rate cannot be negative.

Borders are rule-input at 3.2:1, which clears WCAG 1.4.11 for non-text contrast — the previous input border was 1.4:1 and effectively invisible against the page. Focus is a two-pixel outline with offset, applied consistently; the old kit mixed ring and outline depending on which component you landed on.

FormField generates an id when you do not pass one. The first version prohibited id with Omit<…, 'id'> — auto-generation should be a default, not a ban.

Choice

Radio had zero call sites in the old kit for a simple reason: there was no RadioGroup, so it was unusable. Tabs generated its own baseId with useId() but required the same id as a prop on TabPanel — an ARIA contract that could not be satisfied from outside the component.
