South Asian 2-2-3 grouping via en-IN, with Latin digits. A lakh is 1,00,000 — an operator reading ৳482,150 has to count digits to know whether it is four lakh or forty. The sign is placed outside the symbol, because prefixing ৳ to already-signed output produces ৳-5,000.

en-BD would be the obvious locale and is the wrong one: it resolves to plain en and grouping falls back to 3-3.

These two columns sit beside a quantity, so an operator reads them as an equation. Five rival implementations shipped, using three different numeric-alignment mechanisms — tabular-nums, a .cell-numeric utility, and nothing at all — so figures in adjacent panels did not line up with each other. An absent value renders as an empty marker, never as 0: "we have no figure" and "the figure is zero" are different facts.
