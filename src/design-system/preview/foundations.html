Foundations

Khata (খাতা) is the cloth-bound ledger South Asian traders have kept for centuries, and this console is one. Brass — the tola weights on a balance scale — carries every action and is the only accent. The ground is cool ruled paper, deliberately not the warm cream that every generated admin mock reaches for. Money states take their colour from verdigris, lac and amber, and always carry a shape as well.

No hex or ratio is written on this page, on purpose. The chips read the same generated variables the app compiles, so they cannot show a palette the product no longer uses — which is exactly what this page was doing before Khata landed, having drifted a whole direction behind while claiming precise numbers. Ratios are computed from index.css and asserted in tokens.test.ts; a number repeated in a document is a number that stays convincing long after someone nudges the hex.

Two values in the first Khata draft failed AA and the test caught both: ink-3 at 3.78:1 and ink-4 at 4.23:1 — written from a spec that asserted a 4.6:1 floor nobody had measured, and inverted relative to each other so "tertiary" was lighter than "placeholder". brass-lift was a third: set for looks at 4.1:1 while five call sites used it as text. rule-input targets 3:1 rather than 4.5:1 because WCAG 1.4.11 governs control borders, a different threshold from text and the one most design systems miss.

Inter Tight carries the figures itself, with font-variant-numeric: tabular-nums lining-nums applied globally. Money used to be set in a mono face, which is the common choice and is wrong here: it changes the texture of a number relative to its label, so a table reads as two typefaces arguing. Tabular figures give perfect column alignment — the only property that actually mattered — with no texture break.

IBM Plex Mono is for identifiers only. A SKU, order id or TIN is machine data, read character by character and often transcribed, so disambiguating 1/l and 0/O is worth the texture break there and nowhere else.

Noto Sans Bengali sits second, not last, and that is deliberate: this is a Bangladeshi product and mixed-script cells are normal. Inter Tight's x-height is within ~4% of Noto Sans Bengali's, so the two share a baseline instead of stepping. Fallback is per-glyph, so ৳ resolves through it without changing anything else.

--text-base is 0.875rem, not 1rem. The whole scale is shifted one step down from the web default because this is a data console, not a document. Four weights, and bold is deliberately absent: at 13–14px it reads as noise and semibold already carries the emphasis.

Dropdown sits above modal deliberately. A combobox opened inside a dialog must render over it, and a page-level dropdown can never collide with an open modal because a modal traps focus behind a backdrop.

Two rules learned the hard way, both from bugs that shipped. A step is a page-level rank — applying one inside an already-elevated container makes it rank against its own siblings instead, which is how a dialog backdrop at overlay ended up painting over its own panel at z-index: auto and made every confirm dialog in the app unclickable. And position: sticky resolves against the nearest scrolling ancestor: an unbounded overflow-auto wrapper never scrolls, so a sticky header inside one does nothing at all.
